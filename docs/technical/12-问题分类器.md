# ProblemClassifier — 问题分类器

## 职责

管道第一个执行步骤，极其轻量。将用户请求分类为 4 种任务类型，决定后续走哪条分析路径。

## 四种任务类型

| 类型 | 含义 | 走哪条路 |
|------|------|---------|
| `diagnose` | 功能 Bug：漏报/误报/延迟/状态异常 | 全管线 (evidence + TPE + expert panel) |
| `tune` | 参数优化：调阈值问效果 | ParameterAnalyzer + what-if |
| `verify` | 验证改动：已知方案，验证效果 | ParameterAnalyzer what-if + 数据对比 |
| `query` | 纯数据查询：查速度/列事件 | DataProbe 直接回答 |

## 分类流程 — 两阶段

### Stage 1: 确定性关键词匹配 (零 AI)

```python
# 强信号 (优先匹配)
_DIAGNOSE_HINTS = [
    "没触发", "不触发", "未触发", "漏报", "误报",
    "误触发", "异常退出", "提前退出", "延迟触发",
    "状态.*异常", "状态.*卡住",
    "failure", "miss.*trigger", "false.*alarm",
]

_TUNE_HINTS_STRONG = [
    "调阈值", "调参", "调优", "阈值优化", "参数优化",
    "tune", "tuning", "optimize",
]

_VERIFY_HINTS = [
    "改成.*之后", "改为.*后.*效果", "如果.*改.*会",
    "把.*设为", "验证.*方案", "what if",
]

_QUERY_HINTS = [
    "列出", "查看", "打印", "显示", "导出",
    "between \d", "what is the", "多少次", "多少帧",
]

# 弱信号 (tune 专用)
_TUNE_HINTS_WEAK = [
    "调整.*(?:阈值|ROI|TTC|DDCI|车速|角度|延时|距离)",
    "(?:提高|降低|加大|减小|扩大|缩小).*(?:阈值|ROI|TTC|DDCI|车速|角度|延时|距离)",
]
```

## 显式值提取

```python
# 正则提取 "从 X 改到 Y" 中的 X 和 Y
_EXPLICIT_VALUE_RE = re.compile(
    r"从\s*[-+]?\d+(?:\.\d+)?\s*(?:改到|改成|改为|调到|调至|→|to)\s*[-+]?\d+(?:\.\d+)?",
)
```

## 输出

```python
@dataclass
class ClassificationResult:
    task_type: str          # diagnose | tune | verify | query
    confidence: float       # 0..1
    target_function: str    # BSD/FCTA/... 或 UNKNOWN
    focus_parameters: list[str]  # ["TTC", "ROI"]
    focus_signals: list[str]     # ["car_spd"]
    reasoning: str          # 分类理由
```

## 性能

- 确定性匹配: < 1ms
- LLM 回退: ~2s (仅当确定性匹配失败)
