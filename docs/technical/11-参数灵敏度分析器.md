# ParameterAnalyzer — 参数灵敏度分析器

## 职责

diagnose 管道的兄弟分支，服务于 **tune / verify** 任务类型。纯确定性模块（正则扫描 + 统计对比），不调用 AI，结果可复现。

三大职责：

1. **Inventory（库存）** — 扫描源码，提取所有阈值参数
2. **Sensitivity（灵敏度）** — 计算每个参数在实际数据中的边际情况
3. **What-if（假设分析）** — 评估"如果修改参数 X 为新值，行为会如何变化"

### 输出 — Parameter

```python
@dataclass
class Parameter:
    name: str              # 变量名
    func: str              # 功能 (BSD/FCTA/...)
    category: str          # 类别 (ROI/TTC/...)
    value: float | None    # 数值
```

## 2. Sensitivity — 灵敏度分析

### 算法

```
对每个参数:
1. 找到对应的观测信号 (CATEGORY_OBSERVED 映射)
2. 从 FrameStore 提取该信号的时间序列
3. 计算:
   - 观测值 vs 阈值 的分布
   - 穿越次数 (信号跨越阈值多少次)
   - 边际分布 (|observed - threshold|)
   - 时间占比 (多少比例的时间超过阈值)
```

### 观测信号映射

```python
_CATEGORY_OBSERVED = {
    "SPEED":     ("car_spd_kmh", 1.0),
    "OBJ_SPEED": ("trc_vel_kmh", 1.0),
    "TTC":       ("trc_ttc", 1.0),
    "TTM":       ("trc_ttc", 1.0),
    "DDCI":      ("trc_ddci", 1.0),
    "ANGLE":     ("trc_yaw_angle", 1.0),
    "ROI":       ("trc_dist", 1.0),
    ...
}
```

### 灵敏度指标

```python
@dataclass
class SensitivityAnalysis:
    parameter: Parameter
    crossings: int                    # 穿越次数
    time_above_pct: float             # 超过阈值的时间占比 (%)
    margin_stats: dict                # 边际统计 (min/mean/p50/max)
    observed_distribution: dict       # 观测值分布
    is_critical: bool                 # 是否临界 (边际 < 10%)
```

## 3. What-if — 假设分析

### 算法

```
给定 {param: new_value}:
1. 找到该参数对应的观测信号
2. 重新计算:
   - 新穿越次数 (对比旧值)
   - 新时间占比 (对比旧值)
   - 新边际分布 (对比旧值)
3. 输出 delta:
   - crossings_delta: N → M (+/- X)
   - time_above_delta: A% → B% (+/- Y%)
   - 行为翻转帧数: 多少帧的行为会改变
```

### 输出

```python
@dataclass
class WhatIfResult:
    param: str
    old_value: float
    new_value: float
    crossings_old: int
    crossings_new: int
    time_above_old: float
    time_above_new: float
    flipped_frames: int
    behavioral_change: str  # "更多触发" / "更少触发" / "无明显变化"
```

## 数据流

```
源文件 (adasFunc.c/h, paraDefine.h)
    │
    ▼
正则扫描提取参数
    │
    ▼
Parameter x N (缓存到 parameters.json)
    │
    ▼
对目标功能的参数:
    │
    ├── 从 FrameStore 提取观测信号
    │
    ├── 计算灵敏度指标
    │   - 穿越次数
    │   - 时间占比
    │   - 边际分布
    │
    └── What-if 分析
        - 新值 → 重新计算
        - 输出 delta
```

## 性能

- Inventory 扫描: ~50ms
- Sensitivity 分析: ~20ms/参数
- What-if: ~10ms/假设
- 典型分析 (50 参数): ~1s
