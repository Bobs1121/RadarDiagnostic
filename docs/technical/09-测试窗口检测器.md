# TestWindowDetector — 测试窗口检测器

## 职责

纯规则、零 AI 调用，从 FrameStore 的 egoCarInfo 数据中自动定位实际测试触发时间段。解决"长 bag 录制中只有几秒是有效测试"的问题。

## 检测策略

### 5 类事件检测

| 事件类型 | 检测方式 | 阈值 |
|---------|---------|------|
| `target_appear` | 目标速度 > 0.5 m/s 或距离 > 0.3 m | 持续 >= 3 帧 |
| `state_change` | 状态机值跳变 | 任何跳变 |
| `warning_on/off` | 告警标志值变化 | 任何变化 |
| `speed_cross` | 车速跨越激活阈值 | 功能专属阈值 |
| `warning_edge` | radar_objects 告警边沿 | 来自 warning_events 表 |
| `object_approach` | 目标快速接近 | dist 下降 > 50% |

### Fallback 策略

```python
def _fallback(store, fmap) -> list[TestWindow]:
    """
    三级降级:
    
    1. 目标密度最高区域 (score = 非零目标数)
       → 以最高密度帧为中心，±5s 窗口
    
    2. 数据中段
       → 以时间中点为中心，±5s 窗口
    
    3. 空列表 (极端情况)
    """
```

## 数据结构

```python
@dataclass
class TestEvent:
    t: float              # 时间 (秒)
    event_type: str       # 事件类型
    detail: str           # 详细描述

@dataclass
class TestWindow:
    t_start: float        # 窗口开始
    t_end: float          # 窗口结束
    trigger_reason: str   # 触发原因
    events: list[TestEvent] # 包含的事件
    
    @property
    def duration(self):
        return self.t_end - self.t_start
```

## 性能

- 事件检测: O(N) 其中 N = 帧数
- 窗口合并: O(M log M) 其中 M = 事件数
- 典型 bag (1000 帧, 20 事件): < 100ms
