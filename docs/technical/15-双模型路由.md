# ModelRouter — 双模型路由

## 职责

根据任务复杂度自动选择本地 Ollama 或远程 Qwen3.5-27B 模型。

## 双模型配置

| 模型 | 用途 | 默认地址 |
|------|------|---------|
| Local (Ollama) | 简单任务 | localhost:11434/v1 |
| Remote (Qwen3.5-27B-FP16) | 复杂分析 | 远程 API |

## 复杂度判断

```python
def _estimate_complexity(messages, tools):
    """
    启发式判断:
    - 有 tools (function calling) → complex
    - prompt 超过 4000 字符 → complex
    - 多轮对话 (> 4 messages) → complex
    - 否则 → simple
    """
```

## Thinking Mode

Qwen3.5 支持深度推理模式 (enable_thinking):

```python
if thinking:
    extra_body = {
        "chat_template_kwargs": {"enable_thinking": True},
        "top_k": 20,
    }
    temperature = 1.0
    top_p = 0.95
    presence_penalty = 1.5
```

自动重试机制: 如果 thinking mode 返回空 content，自动降级为非 thinking 重试一次。

## 降级策略

```
simple 模型失败 → 自动 fallback 到 remote
remote 模型失败 → 返回错误信息
双模型都失败 → 返回双错误信息
```

## API

```python
router = ModelRouter(config)

# 简单查询
result = router.simple("查询问题", system="系统提示")

# 复杂分析
result = router.complex("分析任务", system="系统提示",
                        tools=[...], max_tokens=16384, thinking=True)

# 通用接口
result = router.chat(messages, complexity="auto",
                     temperature=0.7, max_tokens=4096,
                     tools=[...], response_format={...})
```
