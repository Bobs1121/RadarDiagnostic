# radarAnalyze 技术文档总览

## 项目简介

radarAnalyze 是一个 AI 驱动的角雷达 (Corner Radar) 问题分析系统，用于 TI AWR2E44P 嵌入式 ADAS 软件的 Bug 诊断和参数调优。支持 ROS1 Bag + Vector CAN BLF + DBC 数据格式。

**技术栈**: Python 3.11, TI AWR2E44P, ROS1, Vector BLF/DBC, SQLite, Plotly, Qwen3.5-27B

## 核心创新

### TPE (Temporal Pattern Engine)

TPE 是本项目最核心的技术贡献：将 C 源码中的时序行为模式 (Hold-Release, Accumulate, Hysteresis, Debounce, EdgeTrigger) 与 CAN 数据中的实际信号时序做因果对齐。

**关键创新点**:
1. **正则提取代码模式** — 从 4 个目标 C 文件扫描 6 类行为模式
2. **时序特征分析** — 对每个 CAN 信号提取 runs, edges, pattern_tag
3. **区间求交算法** — 多变量触发条件的 sweep-line 求交
4. **状态跳变关联** — 自动关联 ±0.5s 内的状态机变化
5. **因果裁决** — triggered / not_triggered / insufficient_data

### 因果链 5 层模型

```
L4 外部表现 → L3 雷达观测 → L2.5 时序耦合(TPE) → L2 ECU 代码逻辑 → L1 CAN 信号输入
```

### 多专家辩论

5 个专业领域专家，3 轮独立分析 + 交叉审查 + 主持人收敛，沿因果链追溯根因。

## CLI 使用

```bash
cd /d/RamboStar/idea/radarAnalyze

# 诊断模式
py -3.11 cli.py cases/FCTA001 -p "FCTA没有触发" -e "应该触发告警"

# 数据查询
py -3.11 cli.py cases/FCTA001 -q "FCTB触发时AEBIB是否激活"

# 记忆巩固 (冷启动自动深度学习源码)
py -3.11 cli.py --dream

# 学习数值常量
py -3.11 cli.py --learn-constants
```

**注意**: 必须使用 `py -3.11` 而非 `python` (Windows Store 占位符问题)。
