# 多层记忆系统 (MemorySystem) — 跨会话知识持久化

## 职责

MemorySystem 是 radarAnalyze 的知识持久化层，灵感来自 Claude Code 的分层记忆架构。它将诊断过程中积累的知识按 6 个层次存储，实现跨会话的经验复用。

## 六层记忆架构

```
L1 — Project Memory       全局项目知识
L2 — Function Knowledge   单功能深度知识
L3 — Pattern Memory       诊断模式库
L4 — Session Memory       单次诊断会话
L5 — Case Memory          单案例持久上下文
L6 — Code Knowledge       代码学习知识 (CodeLearner 产出)
```

### L1: Project Memory

- **文件**: `memory/project.md`
- **内容**: 全局项目约定、系统架构概述、已知问题、模型特定笔记
- **API**:
  - `read_project_memory()` → str
  - `write_project_memory(content)` — 覆盖写入
  - `append_project_memory(entry)` — 追加带时间戳的条目

### L2: Function Knowledge

- **文件**: `memory/functions/{FUNC}.json`
- **内容**: 单功能的深度知识 — 状态机、阈值、关键变量、代码交叉引用
- **特点**: 自动从源码分析填充，诊断经验持续丰富
- **API**:
  - `read_function_knowledge(func_name)` → dict
  - `write_function_knowledge(func_name, knowledge)`
  - `get_all_function_names()` → list[str]
  - `has_function_knowledge(func_name)` → bool

### L3: Pattern Memory

- **文件**: `memory/patterns.json`
- **内容**: 已学习的诊断模式 — 常见根因、症状→原因映射、历史修复建议
- **去重**: 基于内容 MD5 hash，避免重复存储
- **API**:
  - `read_patterns()` → list[dict]
  - `add_pattern(pattern)` — 自动去重
  - `find_similar_patterns(func_name, symptom_keywords)` → list[dict]

### L4: Session Memory

- **文件**: `memory/sessions/{session_id}.json`
- **内容**: 单次诊断的中间发现、推理链、数据快照
- **用途**: 支持恢复和交叉引用
- **API**:
  - `create_session(case_id, problem, expected)` → session_id
  - `log_step(session_id, step_name, detail)` — 记录步骤
  - `log_finding(session_id, finding)` — 记录关键发现
  - `complete_session(session_id, result_summary)`

### L5: Case Memory

- **文件**: `cases/{case_id}/memory.json`
- **内容**: 案例级持久上下文 — 发现了什么、哪些帧重要、最终结论
- **特点**: 与案例数据文件共存

### L6: Code Knowledge

- **文件**: `memory/code_knowledge/{FUNC}.json`
- **内容**: CodeLearner 在 auto-dream 周期中积累的深度代码知识
- **四维度**: alarm_logic, calculation_chain, output_chain, state_machine
- **特点**: 增量增长，Hash 缓存，焦点轮转

## 数据流

```
诊断开始
    │
    ▼
L1 读取项目记忆 (全局架构)
    │
    ▼
L2 读取功能知识 (该功能的状态机/阈值)
    │
    ▼
L3 查找相似模式 (历史类似案例)
    │
    ▼
L4 创建新会话 (记录诊断步骤)
    │
    ▼
诊断执行 (FrameAnalyzer, TPE, ExpertPanel...)
    │ 每个步骤 log_step() 到 L4
    │ 关键发现 log_finding() 到 L4
    │
    ▼
L3 添加新模式 (如果发现了新的根因模式)
    │
    ▼
L2 更新功能知识 (丰富该功能的诊断经验)
    │
    ▼
L4 完成会话 (标记 completed，写入结论)
    │
    ▼
L6 CodeLearner 增量学习 (auto-dream 周期)
```
