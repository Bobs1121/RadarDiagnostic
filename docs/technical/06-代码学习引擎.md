# 代码学习引擎 (CodeLearner) — AI 驱动的源码知识抽取

## 职责

CodeLearner 是项目中**唯一**负责"读源码、抽知识"的模块。它通过 AI 分析 C 语言源码，将嵌入式 ADAS 代码中的结构化知识提取为 JSON 和 Markdown 文档，供后续诊断流程使用。

## 双入口设计

| 入口 | 调用时机 | 输出 | 格式 |
|------|---------|------|------|
| `learn()` | auto-dream Phase 0 | 增量知识 | JSON |
| `ensure_overview_docs()` | orchestrator 启动 | 功能概览 | Markdown |

## learn() — 增量式 JSON 学习

### 学习矩阵

```
功能 (8个) × 焦点 (4个) = 32 个 (func, focus) 对

功能: BSD, LCA, DOW, RCW, RCTA, RCTB, FCTA, FCTB
焦点: alarm_logic, calculation_chain, output_chain, state_machine
```

### 四大焦点

#### 1. alarm_logic — 报警逻辑

- **源文件**: `adasFunc.c/h`, `paraDefine.h`
- **抽取内容**:
  - 触发条件 (if 条件组合)
  - 取消/退出条件 (含迟滞、延时、保压计时器)
  - 外部抑制 (AEB/ESP 等)
  - 迟滞参数 (hysteresis)
  - 计时器 (timers)
- **输出结构**:
```json
{
  "trigger_conditions": [
    {
      "id": "trig-1",
      "c_expression": "if (fFctbTTMX < fFctbObjWarningBaseTTMX && ...)",
      "variables": ["fFctbTTMX", "fFctbObjWarningBaseTTMX"],
      "thresholds": {"fFctbObjWarningBaseTTMX": "1.0s"},
      "code_ref": {"file": "adasFunc.c", "line": 6200}
    }
  ],
  "cancel_conditions": [...],
  "hysteresis": [...],
  "suppression": [...]
}
```

#### 2. calculation_chain — 计算链

- **源文件**: `adasFunc.c`, `objAttribCal.c`, `postProcess.c`, `track.c`
- **抽取内容**:
  - 关键变量计算公式
  - 数据推导链 (原始信号 → 中间变量 → 最终判断量)
  - 使用的阈值/参数
- **输出结构**:
```json
{
  "key_variables": {
    "fFctbTTMX": {
      "formula": "distXRefer / velX",
      "inputs": ["objOutStruct[i].distXRefer"],
      "data_source": "感知层 objOutStruct"
    }
  },
  "derivation_chain": [
    {"step": 1, "from": "radar_targets", "to": "objOutStruct", "transform": "滤波+坐标变换"}
  ]
}
```

#### 3. output_chain — 输出链

- **源文件**: `adasFunc.c`, `ASWOUT_OutCalc.c`, `RteComMapping.c`
- **抽取内容**:
  - 内部输出变量
  - 左右雷达合并逻辑
  - CAN 信号映射
  - 下游消费者
  - 输出门控条件
- **输出结构**:
```json
{
  "outputs": [
    {
      "internal_var": "bFctbKeepBrakeFlg",
      "merge_logic": "左右雷达取 max",
      "can_signal": "CR_BrkgReq",
      "downstream": ["ESP (制动)", "仪表 HMI"],
      "gating_conditions": ["fctbSystemState == 3 (Active)"]
    }
  ]
}
```

#### 4. state_machine — 状态机

- **源文件**: `adasFunc.c`, `ASWIN_SystemState.c/h`
- **抽取内容**:
  - 状态定义 (0-None, 1-Init, 2-Standby, 3-Active, 4-Off, 5-Failure, 6-Passive)
  - 状态转换条件与动作
  - 双状态机交互 (adasFunc vs ASWIN_SystemState)
  - 入口函数调用链
- **输出结构**:
```json
{
  "states": {
    "2": {"name": "Standby", "meaning": "待机"},
    "3": {"name": "Active", "meaning": "激活"}
  },
  "transitions": [
    {
      "from": 2, "to": 3,
      "condition": "bFCTBEnable && vehSpd in [0.5, 21.0]",
      "action": "清空保压计时器；设置 fctbSystemState=3"
    }
  ],
  "dual_state_interaction": [...]
}
```

### 数值常量学习 (全局)

```python
_CONSTANTS_SOURCE_FILES = [
    "adas/symmetry/perception/include/paraDefine.h",
    "coem/GWM_B26/components/AswPerception/calib/dotCalibDefine.h",
    "adas/symmetry/perception/include/globalVarDefine.h",
    "adas/symmetry/perception/include/perception_public_def.h",
    "coem/GWM_B26/components/AswPerception/func/adasFunc.c",
]
```

- **全局一次性任务**，不按 function × focus 轮转
- **输出**: `memory/code_knowledge/constants.json`
- **三分类**:
  1. `vehicle_config`: 基础物理常量 (EGOCARWIDTH, DISTANCEREAR...)
  2. `function_thresholds`: 按功能命名的单值阈值 (fLcaObjWarningTTC...)
  3. `roi_derived`: 推导的 ROI 边界 (LineBSDLCAL = -3.3 - EGOCARWIDTH/2 = -4.288)

### Hash 缓存机制

```
每个源文件计算 MD5 hash → 存储在 learning_state.json
源码未变动 → 跳过已学 (func, focus) 对，零 token 消耗
源码变动 → 重新学习
```

### 焦点轮转策略

```python
# 冷启动: 学满 warmup_pairs 对 (默认 8)
# 热启动: 每次学 pairs_per_dream 对 (默认 2)
# 按 cursor 游标顺序轮转，保证所有 (func, focus) 都能覆盖
```

### 增量合并

```
新条目按 id 去重:
- 内容变更 → 新覆盖旧
- 内容未变 → 跳过
```

## ensure_overview_docs() — Markdown 概览

```python
def ensure_overview_docs(funcs=None) -> None:
    """
    为每个 ADAS 功能生成 Markdown 概览文档。
    输出到 source_docs/{FUNC}.md
    
    结构:
    1. 功能概述
    2. 状态机
    3. 报警/制动逻辑
    4. 关键阈值
    5. 关键变量表
    6. 输入信号
    7. 输出信号
    8. 与其他功能的交互
    """
```

- **触发条件**: MD 文件不存在或源码 hash 变化
- **用途**: 问题理解阶段的上下文素材
- **特点**: 人类可读，不用于程序解析

## 关键词表 (FUNC_KEYWORDS)

## 输出路径

```
memory/code_knowledge/
├── learning_state.json          # 学习状态游标 + hash
├── constants.json               # 全局数值常量
├── FCTB.json                    # FCTB 的 4 个焦点知识
├── RCTA.json
└── ...

source_docs/
├── FCTB.md                      # FCTB Markdown 概览
├── RCTA.md
└── ...
```

## 错误处理

- 源码路径不存在: 跳过，返回 skipped
- 单个 (func, focus) 失败: 记录错误，继续下一个
- LLM 返回格式错误: 重试 (MAX_RETRIES)
- Hash 未变: 零 token 跳过
